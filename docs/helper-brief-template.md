# 翻译帮手简报模板（可选，不用 Model Proxy 时）

`kaggle-lama/translate_sheets.py`（Model Proxy）是默认的翻译方式，
全自动、不需要帮手。这个模板只在你想让另一个 AI（帮手）来翻时用。

## 做法

1. 先裁图，生成图册：

```text
python work/make_crops.py <章节父目录> <章节目录名>
# 产物：<章节目录>/crops/sheet-NN.png（逐框裁图拼册）+ crops.json
```

2. 给帮手的简报**只放三样东西**，不要多给：

```text
翻译这批漫画裁图：<crops 图册路径>
要求：只翻气泡里的对白，翻成简体中文；拟声词、标题、招牌、水印跳过；
按“页#框”编号回译文，例如 001#0、001#1。
```

3. 帮手回译文后，按下面的格式并进章节目录的 `translations.json`：

```json
{"001": [{"box": 0, "zh": "译文"}, {"box": 1, "zh": "译文"}]}
```

拿不准的框不要猜，让帮手单独列出来，人工再定。

## 不要给的东西

实测教训：简报里一旦带上路径清单、术语表、合并指令，帮手会在启动时
被安全策略拦下、零产出。只给图册路径 + 最少要求，一次就能通过。
术语表（`terms/`）是给 `translate_sheets.py` 用的，不用贴进帮手简报；
帮手翻完后你再按术语表统一校对人名即可。
